# MiniWin 1.0 (디버그 빌드)

이번 빌드는 더블클릭이 왜 안 열리는지 진단하기 위한 임시 디버그 빌드입니다.

## 확인해주실 것

1. `./build.sh` 로 빌드
2. `qemu-system-i386 -drive format=raw,file=build/os-image.img` 로 실행
3. NOTEPAD.EXE 아이콘을 **한 번만** 클릭해보세요.
   - 화면 하단에 "CLICK 1 REGISTERED - CLICK AGAIN" 이라는 메시지가 뜨나요?
   - **뜬다면**: 클릭 감지 자체는 정상 작동 중입니다. 이 상태에서 바로 이어서 한 번 더 클릭했을 때 창이 열리는지 확인해주세요.
   - **안 뜬다면**: 클릭 감지 자체가 여전히 안 되고 있다는 뜻입니다. 이 경우를 알려주시면 다른 방향으로 접근하겠습니다.

이 메시지가 뜨는지 여부만 알려주셔도 원인을 좁히는 데 큰 도움이 됩니다.

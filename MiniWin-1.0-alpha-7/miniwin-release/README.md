# MiniWin 1.0 (진단 빌드 v2 - 클릭 간격 측정)

이번 빌드는 두 클릭 사이에 실제로 몇 틱(tick)이 지나는지 화면에 직접
표시합니다. 더블클릭 판정 시간(`double_click_window`)을 정확한 값으로
맞추기 위한 진단용입니다.

## 확인해주실 것

1. `./build.sh` 로 빌드
2. `qemu-system-i386 -drive format=raw,file=build/os-image.img` 로 실행
3. NOTEPAD.EXE 아이콘을 마우스를 고정한 채로 **평소 하시던 대로 두 번**
   클릭해주세요 (더블클릭처럼요).
4. 화면 하단에 뜨는 메시지를 확인해주세요:
   - `CLICK 1: E=0000` → 첫 번째 클릭 (정상, 무시하셔도 됩니다)
   - `NOTEPAD.EXE OPENED` → 창이 열렸다는 뜻입니다 (성공!)
   - `TOO SLOW: E=XXXX` → 두 번째 클릭이 왔지만 시간창을 놓쳤다는 뜻이고,
     `E=` 뒤의 4자리 16진수 숫자가 **실제로 두 클릭 사이에 지나간 tick
     수**입니다.

**이 화면을 캡처해서 `E=` 뒤에 어떤 숫자가 나오는지만 알려주시면 됩니다.**
그 숫자를 보고 정확한 `double_click_window` 값을 계산해서 다음 빌드에
반영하겠습니다.

(이번 빌드는 진단 전용이라 `double_click_window`가 임시로 아주 크게
설정되어 있어서, 두 번 클릭하면 오히려 100% 성공(=바로 열림)할 가능성이
높습니다. 그래도 상관없이, 화면에 뜨는 마지막 상태 메시지를 캡처해서
보여주시면 됩니다.)
